1. 앱에서 직접 삭제 (즉시)

입어봄 앱 실행 → 마이페이지 → 회원 탈퇴

탈퇴를 누르면 개인정보가 즉시 삭제 처리되고, 카카오 계정 연결도 함께 해제됩니다. 별도 승인 절차 없이 본인이 바로 완료할 수 있습니다.

2. 앱 없이 요청 (이메일)

앱을 삭제했거나 접근이 어려운 경우, 아래 이메일로 삭제를 요청해 주세요.

  • 받는 곳: progreneur@gmail.com
  • 제목: [입어봄] 계정 삭제 요청
  • 본문: 가입에 사용한 카카오 닉네임 또는 이메일(본인 확인용)

요청 접수 후 본인 확인을 거쳐 처리하며, 처리 완료까지 영업일 기준 최대 7일이 소요될 수 있습니다.

3. 삭제되는 데이터

탈퇴 시 다음 개인정보가 즉시 삭제(또는 식별 불가 처리)됩니다.

  • 즐겨찾기(찜한 코디) 기록
  • 단말 정보(앱 버전·OS·기기 모델 등)
  • 카카오 로그인 연결 (앱 연결 해제)

항목내용 / 보관 기간
