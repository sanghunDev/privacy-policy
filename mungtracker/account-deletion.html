① 앱 내에서 직접 삭제 (즉시 처리)

앱이 설치되어 있으면 메뉴 4번 탭만으로 즉시 영구 삭제됩니다.

  1. 멍트래커 앱 실행 → 하단 마이 탭
  2. 계정 관리 카테고리 선택
  3. 회원 탈퇴 버튼 선택
  4. 2단계 확인 후 계정 영구 삭제 클릭

⏱️ 처리 시간: 즉시 (영구 삭제, 복구 불가)

② 이메일로 삭제 요청 (앱 삭제 후에도 가능)

앱을 이미 삭제했거나 앱에 접근할 수 없는 경우 이메일로 요청하실 수 있습니다.

📌 계정을 유지하고 일부 데이터만 삭제하기

계정을 유지한 채 특정 데이터만 삭제하실 수 있습니다.

  • 특정 산책 기록 삭제 → 다이어리 탭 → 해당 기록 길게 누르기 → 삭제
  • 반려견 프로필 삭제 → 마이 → 반려견 관리 → 반려견 목록 → 삭제
  • 알림 비활성화 → 마이 → 알림 → 토글 OFF
